## Purpose

为公园和园区巡检提供可持久化的地图区域及设备登记位置，允许授权管理者组织空间视图，并让成员在总览刷新后仍可查看，同时明确登记位置与实时遥测的区别。

## ADDED Requirements

### Requirement: 持久化巡检区域
系统 SHALL 允许项目 owner/admin 按 device:configure 权限登记命名的 WGS84 Polygon 或 MultiPolygon，拒绝无效、越界、不闭合及自交几何；区域仅用于巡检展示，不执行设备控制。快照 SHALL 在同一项目事务中返回这些区域。

#### Scenario: 区域刷新可见
- **GIVEN** 管理者属于当前项目团队
- **WHEN** 登记有效围栏并重新读取快照
- **THEN** 快照返回相同名称和几何，总览可绘制区域

#### Scenario: 无效或越权区域
- **GIVEN** 请求包含自交围栏或者账号没有项目管理权限
- **WHEN** 尝试登记区域
- **THEN** 请求被拒绝且不保存区域

### Requirement: 设备登记位置
系统 SHALL 允许项目 owner/admin 登记现有有效设备类型及静态位置，设备初始离线且没有控制能力；登记位置 SHALL 仅在没有遥测位置时用于地图显示，其来源标识为手动登记，不生成遥测、轨迹、直播或在线连接状态。

#### Scenario: 离线设备显示
- **GIVEN** 管理者选择有效设备类型和位置
- **WHEN** 完成登记并读取快照
- **THEN** 设备显示对应类型图标、名称和位置，状态离线且控制能力为空

#### Scenario: 实时位置优先
- **GIVEN** 手动登记设备后来收到有效遥测位置
- **WHEN** 读取快照
- **THEN** 使用遥测位置而非静态登记位置

### Requirement: 审计与项目隔离
系统 SHALL 在既有审计事务中进行登记，只读取请求项目的数据，并通过项目内登记键避免重复创建。

#### Scenario: 跨项目与重复请求
- **GIVEN** 一个项目已登记某个登记键
- **WHEN** 重复相同项目和登记键的请求，或另一项目读取快照
- **THEN** 重复请求不会新增资源，另一项目快照不包含该资源
