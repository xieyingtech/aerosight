## Purpose

定义司空 OpenAPI 客户端的主机、鉴权、能力探测、错误语义、分页一致性、租户隔离和可观测性契约，使全接口覆盖能够在不同区域、部署版本和账号权限下安全降级而不是盲目宣称支持。

## ADDED Requirements

### Requirement: 请求只能发送到允许的官方主机

系统 SHALL 从部署配置选择固定的 DJI 司空区域主机，并仅通过 HTTPS 发送请求；租户输入的 base URL、重定向目标、代理地址或响应内非允许主机链接 MUST NOT 接收组织 Token、项目 UUID、SN 或短期凭据。

#### Scenario: 上游响应重定向到非允许主机
- **GIVEN** 官方调用返回跨主机重定向
- **WHEN** 客户端评估目标地址
- **THEN** 系统拒绝携带认证信息跟随重定向并产生脱敏诊断

### Requirement: 能力必须通过运行时探测和静态契约求交集

连接器 SHALL 为系统健康、项目权限、设备型号以及设备、任务、直播、地图、建模和管理功能建立版本化 capability matrix；UI/API 只能暴露官方契约声明、当前区域/部署支持、账号权限允许、AeroSight 已实现且相应风险验收通过的交集。

#### Scenario: 私有化专属接口用于公有云连接器
- **GIVEN** 官方目录包含当前公有云不支持的接口
- **WHEN** 能力探测完成
- **THEN** 系统将该能力标为不适用并隐藏执行入口
- **AND** 不把 404/不支持持续报告为连接器故障

#### Scenario: 能力探测需要破坏性调用
- **GIVEN** 某能力只能通过写操作确认
- **WHEN** 系统执行自动探测
- **THEN** 系统不得调用该接口
- **AND** 能力保持“未现场验证”直到专门验收

### Requirement: 业务码和 HTTP 错误必须归一化

客户端 SHALL 同时解释 HTTP 状态、司空业务 code 和响应 schema，将成功、合法空状态、权限不足、参数缺失、能力不支持、限流、认证失效、暂时故障和不兼容响应映射为稳定错误类别；原始响应正文 MUST NOT 直接传给用户或日志。

#### Scenario: 分享列表返回无资源业务码
- **GIVEN** HTTP 响应包含官方定义的“当前无资源”业务码
- **WHEN** 客户端归一化结果
- **THEN** 调用方得到空集合和健康响应而不是平台故障

#### Scenario: 云控接口缺少上下文参数
- **GIVEN** 司空返回参数错误业务码
- **WHEN** 客户端处理响应
- **THEN** 系统记录安全的参数类别诊断并保持能力未验证
- **AND** 不误判为 Token 失效或设备离线

### Requirement: Token、SN 和临时凭据必须最小化处理

组织 Token SHALL 使用现有 credential envelope 加密保存且只在 Worker 必要生命周期解密；SN 解密结果、STS 凭据、签名 URL、直播 Token 和原始厂商错误 MUST 采用最小保存、字段级脱敏和短有效期策略，且不得进入浏览器持久化、日志、trace、指标标签或普通审计输入。

#### Scenario: 获取 STS 上传凭据
- **GIVEN** 受控上传流程需要临时凭据
- **WHEN** 系统从司空获取 STS 响应
- **THEN** 凭据仅绑定当前项目、操作和有效期使用
- **AND** 过期后不可从数据库或可观察输出恢复明文

### Requirement: 分页、限流和重试不得破坏一致性

所有列表和全量同步 SHALL 遵循官方分页/上限并记录可恢复游标；429、5xx、网络超时和未知写结果必须采用有界退避、抖动和幂等规则。无法证明完整性的批次 MUST NOT 推进完整快照游标或处理缺失资源。

#### Scenario: 目录达到接口上限且无完整性证明
- **GIVEN** 一次请求返回恰好官方上限且没有下一页或总数证明
- **WHEN** 系统评估完整快照
- **THEN** 本轮标记不完整并保留已有资源
- **AND** 不把未返回资源标记为 missing 或删除

### Requirement: 所有数据和操作必须保持租户隔离

司空资源、同步游标、远端标识、能力、命令、媒体和诊断 SHALL 以 AeroSight `project_id` 与 Connector Instance 为强制作用域；任何读取、更新、订阅或下行操作 MUST 先通过团队成员关系和对应项目权限授权。

#### Scenario: 两个项目连接同一司空项目标识
- **GIVEN** 不同团队项目各自配置了相同远端项目 UUID
- **WHEN** 任一项目同步或操作资源
- **THEN** 数据、凭据、游标和审计保持独立
- **AND** 用户不能通过远端 UUID 枚举另一项目资源

### Requirement: 全接口覆盖必须有可审计证据

系统 SHALL 为官方 released 接口目录维护版本化契约清单，记录每个接口的实现状态、fixture 验证、真实只读验证、现场写入验证、最后验证时间和已知限制；连接器诊断页 MUST 使用该清单说明实际支持度而非笼统显示“已连接”。

#### Scenario: 官方新增或修改接口
- **GIVEN** 契约清单检测到官方文档路径、方法或 schema 变化
- **WHEN** 发布前兼容性检查运行
- **THEN** 未重新验证的能力标为待兼容验证
- **AND** 高风险写能力不会因文档新增而自动开放
