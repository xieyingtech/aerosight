## Purpose

定义 AeroSight 对司空直播、录制、直播分享和码流转发的统一会话与安全边界，兼容上游动态选择的媒体供应商，并保证播放凭据、并发资源和最终状态可治理、可恢复。

## ADDED Requirements

### Requirement: 直播必须适配上游返回的供应商

系统 SHALL 从司空启动直播响应识别实际供应商、协议、播放信息和有效期，并通过供应商适配层建立统一 `live_stream` 会话；系统 MUST NOT 假定固定为火山、声网、SRS 或任一单一供应商。

#### Scenario: 司空动态返回受支持供应商
- **GIVEN** 授权用户为在线设备通道启动直播
- **WHEN** 司空返回一种已配置供应商的临时播放信息
- **THEN** 系统建立统一会话并向浏览器提供短期授权播放能力
- **AND** UI 不暴露供应商专用秘密

#### Scenario: 返回未知供应商
- **GIVEN** 司空返回当前部署未适配的供应商
- **WHEN** 系统解析启动响应
- **THEN** 系统撤销本地播放授权、销毁短期凭据并显示兼容性原因
- **AND** 会话记录远端状态未确认且不得调用未发布的停止接口或宣称远端已停止

### Requirement: 直播会话必须与远端状态对账

启动、停止意图和恢复直播 SHALL 使用统一会话状态机。启动 SHALL 调用 released `POST /openapi/v2.0/live-stream/start`；由于 released 契约没有停止直播或查询会话状态的 endpoint，停止意图 SHALL 立即撤销本地播放授权、销毁短期凭据并进入 `stopping`，MUST NOT 调用未进入 endpoint manifest 的停止接口。系统 SHALL 使用新鲜物模型 `live_status`、设备在线状态、凭据到期和官方五分钟无观众规则周期对账；只有证据足以证明推流终止时才可进入 `stopped`，证据缺失或矛盾时 MUST 保持可解释的 `stopping`/`failed` 未确认状态而不得误报成功。

#### Scenario: 用户请求停止直播
- **GIVEN** 本地会话处于 `starting`、`live` 或 `degraded`
- **WHEN** 授权用户请求停止
- **THEN** 系统立即撤销播放授权并销毁供应商短期凭据
- **AND** 会话进入 `stopping`，且不会向司空调用未发布的停止接口
- **AND** 仅在后续证据证明推流终止后进入 `stopped`

#### Scenario: 上游因无观众自动停止
- **GIVEN** 司空直播已开始且在规定时间内无观众
- **WHEN** 上游停止推流并被对账器发现
- **THEN** 本地会话结束并释放占用
- **AND** UI 不继续展示虚假在线画面

#### Scenario: Worker 在直播中重启
- **GIVEN** 本地会话处于 `starting`、`live` 或 `stopping`
- **WHEN** 新 Worker 取得连接器租约
- **THEN** 系统使用持久非秘密状态和最新远端证据恢复对账
- **AND** 不因租约过期、响应未知或重启本身将会话标记为 `stopped`

#### Scenario: 远端证据不可用或互相矛盾
- **GIVEN** 会话启动响应未知，或物模型、设备状态与凭据生命周期不能证明同一终态
- **WHEN** 对账器达到本次核对截止时间
- **THEN** 会话保持 `stopping` 或进入带稳定原因码的 `failed`
- **AND** 系统不得盲目重发启动请求或宣称远端已停止

### Requirement: 媒体秘密不得持久泄露

播放 URL、推流 URL、访问 Token 和供应商凭据 SHALL 视为短期秘密，仅在必要生命周期内加密保存或按需获取；系统 MUST NOT 将其写入普通日志、trace 属性、指标标签、审计输入、浏览器持久化或无授权 API 响应。

#### Scenario: 启动直播响应包含 URL 和 Token
- **GIVEN** 司空返回带签名 URL 或 Token 的播放信息
- **WHEN** 系统记录调用与审计
- **THEN** 记录仅包含会话标识、供应商、状态和脱敏错误
- **AND** 播放信息只返回给当前项目内获授权的短期会话

### Requirement: 录制、分享和码流转发必须受独立授权

系统 SHALL 分别暴露录制配置/控制、直播分享和码流转发能力，并对读取、创建、更新、停止和删除使用可区分权限；不存在资源的官方业务码 SHALL 映射为空状态而不是平台故障。

#### Scenario: 当前没有直播分享资源
- **GIVEN** 司空以约定业务码表示没有分享资源
- **WHEN** 用户查看分享列表
- **THEN** UI 展示可操作空状态且连接器健康不受影响

#### Scenario: 普通成员尝试创建码流转发
- **GIVEN** 用户只有直播查看权限
- **WHEN** 用户提交码流转发配置
- **THEN** 系统拒绝请求且不调用司空写接口
