## Purpose

定义司空所有主动控制、设备维护和组织管理写操作进入 AeroSight 时必须遵守的能力、权限、安全、审批、幂等和结果对账边界，确保“接口可调用”不等同于“现场可安全开放”。

## ADDED Requirements

### Requirement: 所有设备指令必须经过统一命令账本

返航、取消返航、任务暂停/恢复、控制权、云控实时指令、相机/镜头切换和 TCA 等设备操作 MUST 先校验项目 RBAC、设备范围、Driver 与运行时能力交集、在线新鲜度、安全策略和风险确认，再创建带幂等键、截止时间和请求者的命令记录后调用司空。

#### Scenario: 返航请求同步受理
- **GIVEN** 飞行器在线、能力可用且操作者通过高风险确认
- **WHEN** 司空 HTTP 接口接受返航命令
- **THEN** 命令只进入已受理/等待结果状态
- **AND** 系统等待可关联的远端状态或事件后才确认物理结果

#### Scenario: 状态过期时提交控制
- **GIVEN** 设备最后物模型状态超过控制新鲜度阈值
- **WHEN** 用户提交任何主动飞行控制
- **THEN** 系统拒绝投递并记录触发的安全规则

### Requirement: 连续控制必须使用受限会话

云控状态、控制权取得/释放和实时指令 SHALL 绑定短期独占会话、操作者、目标设备、心跳、频率限制与自动失效；会话中断、权限撤销或设备状态异常时 MUST 立即停止继续发送指令并尝试安全释放控制权。

#### Scenario: 控制会话心跳中断
- **GIVEN** 操作者已取得控制权并开始实时控制
- **WHEN** 客户端或服务心跳超过失效阈值
- **THEN** 系统停止下发新指令并结束本地会话
- **AND** 按司空能力尝试释放控制权并记录未知结果

### Requirement: 维护和迁移动作默认关闭

RTK 标定、中继对频、设备迁移、SN 解密及其他影响设备归属或现场配置的动作 SHALL 默认关闭；仅当 capability probe、项目 owner/admin 权限、功能开关、二次确认/审批和针对型号的现场验收全部通过时才可开放。

#### Scenario: 未完成现场验收的设备迁移
- **GIVEN** 司空账号可能具备迁移 API 权限但当前环境未验收
- **WHEN** 管理员尝试迁移设备
- **THEN** 系统拒绝操作且不调用上游
- **AND** 说明缺少的验收或功能开关

#### Scenario: 已批准的 RTK 标定失败
- **GIVEN** 已通过审批的 RTK 标定被司空受理
- **WHEN** 远端返回失败或结果未知
- **THEN** 命令账本保留真实结果、响应时间和安全上下文
- **AND** 系统不自动重复执行物理动作

### Requirement: 组织与项目管理写操作必须使用管理域授权

组织、项目、成员、角色和权限的读取 SHALL 与设备操作权限分离；创建、更新、删除或成员权限变更 MUST 要求显式管理域授权、目标范围校验、差异预览、二次确认和完整审计，且不得通过普通项目成员权限间接获得。

#### Scenario: 项目管理员缺少组织管理权
- **GIVEN** 用户是 AeroSight 项目 admin 但未获组织管理 capability
- **WHEN** 用户尝试修改司空组织成员或角色
- **THEN** 系统拒绝操作且不调用司空管理接口

#### Scenario: 删除操作已获授权
- **GIVEN** owner 具备专用管理权限且功能已启用
- **WHEN** 用户确认删除远端资源
- **THEN** 系统展示精确目标和不可逆影响并记录审批
- **AND** 执行后重新读取远端状态完成对账

### Requirement: 高风险能力必须逐项现场验收

系统 SHALL 为每个区域、部署类型、账号、设备型号、固件和 action code 记录只读探测、模拟验证与现场验证状态；只有标记为现场通过的高风险能力才可被运行时 capability manifest 启用。

#### Scenario: 新固件尚未复验
- **GIVEN** 已验收设备升级到超出兼容矩阵的新固件
- **WHEN** 系统重新计算有效能力
- **THEN** 高风险动作降级为不可用并保留只读诊断
