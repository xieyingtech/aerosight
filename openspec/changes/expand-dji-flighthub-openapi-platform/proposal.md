## Why

现有 DJI 司空 2 连接器只同步设备目录，没有消费物模型状态、任务、直播、地图空域和建模等 OpenAPI 能力；已纳管的 Dock 与飞行器因此没有 `poses`，即使司空真实返回经纬度也无法出现在地图上。现在需要把已验证的司空公有云能力接入统一设备平台，并用能力探测和安全治理区分“可读”“可操作”和“尚未现场验收”的功能，避免继续以静态目录或过度承诺替代真实集成。

## What Changes

- 扩展 `dji.flighthub2` Worker，从官方物模型状态读取 Dock/飞行器位置、姿态、网络、电池、工作模式和直播状态，投影到统一设备状态、遥测、时空位置和实时通道，修复地图无位置及 `aircraft` 分类问题。
- 同步 HMS、历史拓扑、自动录制配置及数据新鲜度，并将业务空结果、权限不足、能力不支持、限流和平台故障归一化为可解释状态。
- 接入航线、飞行任务、任务状态、轨迹、媒体和 AI 告警，复用现有任务运行、资产、问题/感知事件和审计基础设施。
- 接入直播启动、本地播放授权撤销与证据驱动的会话停止对账，以及录制、分享和码流转发；适配司空动态返回的多直播供应商，并保护短期播放 URL/Token。当前 released 契约没有远端停止或会话查询接口，系统不得虚构调用或在缺少证据时宣称远端已停止。
- 接入地图标注、飞行区、离线地图与 AirSense 告警，并显式处理 GeoJSON、坐标系和项目级全量同步边界。
- 接入模型列表、重建任务和开放建模能力，保留远端标识、进度、产物与失败诊断。
- 将航线上传、任务创建/更新、返航/暂停/恢复、控制权、相机/镜头、TCA、RTK、中继对频、设备迁移及组织管理等写操作纳入统一 RBAC、安全策略、审批、幂等命令账本和结果对账；高风险或未现场验收能力默认关闭。
- 增加连接器能力探测与区域/部署类型兼容矩阵；公有云、私有化专属、账号权限或设备型号不支持的接口不向 UI/API 宣称可用。
- 修正连接器生命周期：已禁用/断开的实例不得继续产生新绑定、同步或控制；历史设备与数据保留为只读并显示来源状态。
- 不以本次规划承诺 89 个接口都默认可写。目标是为所有官方功能建立真实契约、适配入口和验证路径，按只读数据、低风险写入、高风险现场控制分阶段启用。

## Capabilities

### New Capabilities

- `dji-flighthub-device-state`: 司空设备物模型、位置、遥测、状态、HMS、历史拓扑及连接器生命周期投影。
- `dji-flighthub-flight-operations`: 航线、远端飞行任务、任务状态、轨迹、媒体、飞行记录和 AI 告警同步与受控写入。
- `dji-flighthub-live-media`: 多供应商直播、录制、分享、码流转发、会话对账和秘密保护。
- `dji-flighthub-geospatial`: 地图标注、飞行区、离线地图、AirSense 告警与坐标标准化。
- `dji-flighthub-modeling`: 模型目录、重建任务、开放建模进度及产物关联。
- `dji-flighthub-governed-actions`: 设备控制、控制权、RTK、对频、迁移及组织管理等写操作的统一治理和现场验收门槛。
- `dji-flighthub-capability-security`: 官方主机限制、能力探测、权限/错误归一化、敏感数据处理、租户隔离与可观测性。

### Modified Capabilities

无。当前 `openspec/specs/` 尚无已归档的主规格；本变更以新能力规格承接并收紧已完成变更中的司空连接器行为。

## Impact

- Worker：`apps/worker/internal/flighthub` 客户端、运行时调度、重试/限流、状态与任务同步器，以及 Connector/outbox/command ledger 对账。
- Web/API：连接器诊断、设备详情与地图、任务/航线、直播、地图空域、建模和受控操作页面；所有项目资源继续通过团队成员关系授权。
- 数据：优先复用 `devices`、`device_telemetry`、`device_latest_telemetry`、`observations`、`poses`、`device_commands`、`command_attempts`、`task_runs`、`assets`、`live_streams`、`issues`、`perception_events` 与现有审计/审批表；仅在这些模型无法表达远端状态时增加项目级投影表和迁移。
- 外部系统：DJI 司空 2 中国大陆公有云 OpenAPI v2、动态直播供应商和短期对象存储 URL；请求只能发往部署允许列表内的官方 HTTPS 主机。
- 兼容性：现有目录同步和历史数据保持可读；新字段/表采用向前迁移，未具备权限或未验收的能力表现为不可用而不是破坏现有连接。
- 非目标：不绕过司空 OpenAPI 接入 DJI Cloud API 直连，不把 HTTP 受理误判为物理执行成功，不默认开放 DELETE、组织权限变更、设备迁移或其他高风险现场动作。
