## Why

本地实验已验证视频描述、E5 和 Qdrant，但正式素材导入、后台任务、智能体及证据预览尚未连接。需要将这些能力接入正式服务，避免依赖临时脚本。

## What Changes

- 新增素材语义索引后台任务，自动发现图片和视频，生成分段视觉描述及向量，持久化重建材料。
- 增加失败重试、状态查询、重建及失效索引清理。
- 增加当前项目限定的语义搜索和智能体只读工具，回表核验素材版本、删除状态与权限。
- 素材库展示索引进度、语义搜索及视频片段跳转。
- 提供本地 CPU E5 服务及 Docker 配置，使用隔离数据库验证真实素材链路。

## Capabilities

### New Capabilities
- `media-semantic-search`: 素材自动语义索引、可靠投影、权限安全搜索和证据引用。

## Impact

Go runtime、HTTP API、Agent 工具、素材库、数据库迁移、Docker 镜像和部署配置。Qdrant 为派生索引，PostgreSQL 与对象存储为重建来源；默认不开启，启用需显式配置模型及服务。
