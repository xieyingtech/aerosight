## Context

Go 统一服务有多个素材生成入口。轮询 PostgreSQL 中可用的图片与视频，利用唯一约束补齐持久化任务，覆盖导入和外部同步。所有实验脚本与凭据继续放在忽略目录。

## Goals / Non-Goals

目标为上传到检索及证据预览的实际闭环、重启恢复和可重建索引。原阶段仅本地验证；按 2026-10-10 用户授权追加线上部署，不把视觉描述当成确定违规判断。

## Decisions

- 模型空间由名称、固定 revision、维度及分析流程版本生成；空间变更自动产生新任务和 collection，避免向量混用。
- 视频按十秒窗口采样三帧，图片单段；实际文件经过 SHA256 检查。ffprobe/ffmpeg 有超时和大小限制，错误可见，不静默截断。
- 任务持久化，使用 PostgreSQL session advisory lock 防止并发重复处理；失败带退避，可手动重试。处理过程中不持有长业务事务。
- 每个分段生成后保存内容寻址的不可变检查点并更新任务指针；中断后校验来源并跳过已完成窗口。对象写入成功而数据库指针更新失败时，旧检查点仍然可用，不覆盖已记录校验和的对象。
- 对象存储保存描述和向量 JSON，数据库记录素材快照与片段事实；Qdrant 丢失后可以从材料恢复。源版本变更或删除后查询立即回表排除，后台随后清理向量。
- 仅可信拍摄时间可用于绝对时间过滤；用户未验证时间或上传时间不能充当真实拍摄时间。不从视觉内容推断坐标。
- Agent 仅能搜索当前会话项目；HTTP 与工具均先授权、检索后再次授权，素材返回前核验权限。结果包含模型描述不确定性、片段区间和预览引用。
- 默认关闭索引；配置完整才启用。独立 E5 HTTP 服务供 Go 调用，验证 revision、维度和归一化，模型固定在缓存或镜像中。

## Risks / Trade-offs

全量视频分析消耗 VLM 配额；当前每次处理一个任务，有明确大小、时长上限。远程素材可能暂不可读，失败需保留原因和重试状态。Qdrant 故障不阻塞上传或核心业务；搜索报告不可用，后台退避恢复。

## Migration Plan

添加任务和片段表以及 schema 快照；默认关闭无行为变化。本地隔离数据库验证后由部署者设置连接与模型配置。回滚关闭开关，保留重建材料与事实数据。

## 用户授权的线上部署

在既有 Zeabur 项目创建私网 Qdrant v1.19.0，持久化 /qdrant/storage，独立随机 API Key；部署既有 E5 CPU 服务，固定模型/revision/384 维并设置独立密钥。依赖健康后才启用 SEMANTIC_ENABLED，使用合成视频通过正式上传 API 验证，不直接写生产数据库或重建既有 collection。事实仍来自 PostgreSQL，重建材料仍在 OSS。
