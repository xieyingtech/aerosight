## Context

当前有 115 张业务物理表（包含遥测默认分区）。0090 首轮合并为 91 张，0091 精简为 87 张，0092 合并三组活跃的一对一扩展至 84 张；schema_migrations 为运行时迁移账本，单独计算。

## Goals / Non-Goals

压缩重复结构并保留历史证据、幂等、重试和租户约束。此次不改巡检业务语义、不增加 Qdrant、不开启尚未上线的自动化或保留策略。

## Decisions

统一作业表使用 job_type 区分八种类型，以条件 CHECK 保留各类状态与字段约束，以类型参与幂等键。旧名称改为过滤视图，只有一份物理数据；upsert 改写至基表。保留开放模型上传凭据会话表。

检测直接关联 group_id；巡检策略放在设备适配器；私有告警证据放在远程资源私有列，不进入公开摘要；业务 Run/Step 放在飞行作业，保留与物理飞行 Run 的区分；案件来源放在 issue_links；智能体证据保存为草稿 JSON 快照。平台审计合并后用 scope 区分并保存旧平台记录 ID。

不修改已发布迁移。删除模块前将有数据的旧记录及即将删除的历史引用归档到 audit_events，由 system actor 记录一次性迁移来源。FK 清理仅替换历史成员引用，保留项目与对象组合外键。

视频帧 URL 从受支持的对象存储生成短期签名链接，不为每个帧创建 assets；调用诊断写入帧级 OSS 文件。视频级摘要节流更新，完整 JSONL 结果及原视频关联保持不变。

## Alternatives

0092 为父表新增有类型的扩展列，并以条件 CHECK 约束扩展完整性；保留协议事务/业务号唯一键及组合项目 FK、访问摘要唯一键、位置 PointZ 和时间/GiST 索引。协议关联原 bigserial ID 保留并转移序列归属。位置子记录的 device_id/captured_at 可能不同于父观测，迁移分别保留，不根据当前写入方式覆盖历史。

三张旧表改为过滤视图；兼容扩展写入/删除通过触发器只修改父表扩展列，不删除父记录，扩展更新不移动父记录身份。运行时新建协议关联和访问引用直接更新父表；遥测位置一次 INSERT 同时保存观测与姿态。连接器/远程资源被删时清除访问扩展，适配器被删时清除协议扩展，位置设备被删时清除位置扩展，保持原子表级联效果且不误删父对象。素材 API 保持显式公开字段投影，私有访问凭据保持原资产 ID 的加密 AAD。

逐表审计不能将生成代码、测试造数或未调用查询当作业务使用；写入中的唯一键、RETURNING、UPSERT 时间比较和外键消费也是实际使用。保留协议 inbox/cursor、遥测去重、自动分区、迁移种子目录、显式授权和有来源 FK 的同步批次。

0091 将上传原文件名放到素材 metadata 的 uploadFileName，旧事件只读反馈放到父事件 legacy_feedback_json；旧证据完整行归档且已发布素材保留敏感下载、删除及标志保护。派生素材直接记录主来源 FK/类型，保留生成器参数和重试；历史多来源完整边归档并确定性选择最早主来源。退役表全部完整归档。缩略图 asset.available 消费者已注册，当前导入未发布该事件，保留消费者以兼容旧队列，不将它描述为当前导入功能。

完全移除类型视图会导致所有作业读取同时更换模型，增加兼容性风险；类型视图不存数据且明确隔离业务类型，因此保留。单一 JSON 作业负载难以保留现有 SQL 外键和字段校验，选择公共字段加类型专属可空列。

## Migration Plan

新增事务迁移：归档、建统一表、搬迁、合并关系、删除旧表、建立视图及重新关联外键。重复 UUID 或非法跨项目来源必须失败回滚。由迁移后的本地数据库生成快照与 sqlc。验证全量新建和有历史数据的升级。

## Risks

迁移需取得表锁，应在业务低峰实施；归档仍存现有审计表，生产上线前需正常数据库备份。改名视图不可使用 ON CONFLICT，所有此类写入改为统一基表并显式指定 job_type。
