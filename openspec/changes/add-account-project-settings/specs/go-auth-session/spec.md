## ADDED Requirements

### Requirement: 改密撤销旧会话

系统 SHALL 在密码变更后拒绝该用户所有旧会话，并在实时连接的既有 15 秒复查周期内撤销访问；其他用户会话不受影响。未修改密码的历史账号和已有会话 MUST 保持兼容。

#### Scenario: 多端会话撤销
- **GIVEN** 同一账号在多个客户端登录
- **WHEN** 一个客户端成功修改密码
- **THEN** 所有旧 Cookie 请求受保护 API 返回 401，实时连接在复查周期内结束，新密码重新登录生成有效会话

#### Scenario: 升级兼容
- **GIVEN** 升级前会话未记录凭据版本且账号尚未修改密码
- **WHEN** 升级后请求 session
- **THEN** 会话仍可使用；之后改密即撤销该历史会话
