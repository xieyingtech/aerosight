## Context

现有素材列表已通过授权 API 获取名称/来源，语义搜索返回授权片段。前端静态导出，Go 将资源路径映射到静态详情模板。

## Goals / Non-Goals

**Goals:** 一个搜索框、文字结果优先、素材去重、表格和独立详情、旧链接兼容。

**Non-Goals:** 不改变模型、数据库或权限策略。

## Decisions

- 输入变化立即过滤名称/来源，防抖 350ms 后请求语义 API；Enter 可立即请求。精确等值优先于包含匹配，所有文字匹配优先于纯语义结果。复用现有 API，避免新增后端聚合接口。
- 每素材一行，按语义返回顺序补充未匹配素材，内部保留多个命中区间，表格仅显示简短匹配类型，不展示片段卡片、区间列表或描述，保持紧凑行高。
- 请求中止及代次检查防止旧结果覆盖新关键词；失败仅提示内容检索不可用，保留文字结果。清空恢复全部，类型过滤作用于合并结果。
- 使用 `/projects/:projectId/assets/:assetId/` canonical 路由和静态 `assets/detail` 模板，详情授权素材列表中定位，原片访问继续校验权限。旧 `assets/?assetId=` 链接跳转详情，startMs/endMs 保留。
- 列表行支持点击和键盘，素材名称有真实详情链接，纯内容匹配默认定位最高排名片段。返回列表保留关键词及分类。

## Risks / Trade-offs

- [语义服务延迟或关闭] → 名称/来源结果立即可用，并展示独立状态。
- [近邻不等于事实] → 明确内容匹配供定位复核，详情打开原片。
- [旧证据失效] → 保留入口跳转和时间参数，测试路由映射。

## Migration Plan

同步发布静态前端和 Go 映射，无数据迁移。回滚代码即可恢复旧界面。

列表时间统一显示 created_at，列名“创建时间”；captured_at 继续保存为可选业务元数据，详情和可信时间检索保持原有语义。
