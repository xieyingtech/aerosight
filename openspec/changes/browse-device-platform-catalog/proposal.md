## Why

设备类型页目前只展示卡片和图标编辑，无法查询设备类型与驱动、能力和其他稳定键的关系。需要把它改为平台设备定义目录，便于管理员查阅。

## What Changes

- 设备类型使用表格，去掉目录页图标编辑。
- 提供设备类型、驱动、能力、数据通道和操作五个 tab，统一关键字搜索。
- 展示数据库类型/驱动定义以及平台操作目录的真实键、版本、关联关系和 schema 详情。
- 明确目录声明不代表具体设备在线或具备当前执行权限。

## Capabilities

### New Capabilities

- `device-platform-catalog`: 平台设备定义与相关键的只读浏览和查询。

### Modified Capabilities

无。

## Impact

扩展管理员只读 API 和 sqlc 查询，重做现有设备类型页面。无需迁移或新增依赖。保留原有图标数据、地图展示和兼容 API；不新增类型编辑、实际控制或项目数据查询权限。
