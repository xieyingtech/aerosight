## Purpose

让 Task 根据经过校验与复核的研判确定性地处理案件，隔离司空旧告警自动建案的旁路，保留来源级防重和可导航证据链，以最少新机制完成可靠业务闭环。

## ADDED Requirements

### Requirement: Task 接管告警写案

系统 SHALL 对显式 Task 管理资源仅同步告警证据，禁止同步直接创建、更新、关闭或重开案件；未确认归属的告警先暂存，未接管资源保持旧策略。

#### Scenario: 早到告警

- **GIVEN** 连接器启用 Task 管理模式且飞行归属尚在对账
- **WHEN** 告警先于绑定到达
- **THEN** 暂存证据而不自动建案，归属确认后交对应策略处理

#### Scenario: 重放或缺失同步

- **GIVEN** 告警已由 Task 管理
- **WHEN** 告警更新、重复同步或从列表消失
- **THEN** 不绕过 Task 改动案件；未管理资源原行为仍可回归验证

### Requirement: 决策与来源防重

系统 SHALL 仅消费正式研判，按项目及稳定告警/资产检测来源防重而不含 taskVersion；update 只接受明确本项目关联或人工确认，闭案新观察进入复核。案件/证据/审计和步骤结果须原子提交。

#### Scenario: 同来源重分析

- **GIVEN** 原告警已经建案且发布了 Task 新版
- **WHEN** 再次分析同一来源或并发重放
- **THEN** 不重复建案、不加重复发生次数、不重开旧案；no_issue 返回空案件结果

#### Scenario: 不能确定更新对象

- **GIVEN** 新架次无稳定对象关联、旧案已关闭、needs_review 未确认或事务审计失败
- **WHEN** 尝试自动更新/建案
- **THEN** 模糊关联及闭案新观察要求复核，待复核不写案；事务失败不留半批结果

### Requirement: 证据报告和反馈

系统 SHALL 复用案件反馈与报告入口，支持无案件报告和待复核摘要，可追溯 Task/Run/远端飞行/原图/识别/研判；受项目权限约束且失效临时资源有明确状态。

#### Scenario: 零案件报告

- **GIVEN** 正式研判为 no_issue
- **WHEN** 案件步骤成功返回空列表并生成报告
- **THEN** 报告显示实际范围、来源、模型及零案件，用户可回到证据

#### Scenario: 媒体失效或越权

- **GIVEN** 原图签名过期或用户失去权限
- **WHEN** 打开证据链
- **THEN** 有权限时尝试刷新稳定资源引用，仍失败展示失效；越权拒绝且不泄露签名链接
