## Purpose

为参赛闭环中的顺序步骤提供统一可观察的执行边界，使远端飞行、识别、研判和案件写入可以恢复和追溯，避免设备依赖、无效输出或迟到事件破坏业务运行结果。

## ADDED Requirements

### Requirement: 顺序依赖与输出验证

系统 SHALL 在本次 v2 能力执行前校验前序依赖、条件、引用及输入，成功前验证输出；条件为假无副作用，错误输出或失败依赖不能启动消费者。

#### Scenario: 合法前序输出

- **GIVEN** 观察与识别依次成功
- **WHEN** 研判读取 evidenceSetId
- **THEN** 读取本 Run 已提交的合法输出，按顺序运行

#### Scenario: 失效依赖

- **GIVEN** 前序失败、被跳过或输出不符 schema
- **WHEN** 下游准备运行
- **THEN** 下游不产生外部副作用，Run 展示明确失败/依赖不可用原因

### Requirement: 恢复与未知副作用

系统 SHALL 保留已完成步骤并以稳定作业身份恢复；未知飞行提交不得自动重试。取消/暂停后的迟到事件不得推进案件，普通恢复不能绕过人工复核。

#### Scenario: 重启恢复

- **GIVEN** 识别已成功，后续作业尚未提交
- **WHEN** 服务重启并重放事件
- **THEN** 不重复识别或飞行，仅恢复未完成工作

#### Scenario: 迟到或未知回执

- **GIVEN** Run 已取消或远端提交结果未知
- **WHEN** 收到迟到结果或重试请求
- **THEN** 结果可留痕但不推进取消 Run；未知提交暂停待对账，不发第二次飞行

### Requirement: 业务运行独立于设备投影

系统 SHALL 允许无设备的既有证据工作流，并区分连接器投影 Run 与业务 Run；远端飞行成功不能代表整个业务流程成功。

#### Scenario: 离线分析

- **GIVEN** 授权资产或已完成飞行可读且无在线设备
- **WHEN** 启动 P0 模板
- **THEN** 进入证据及研判步骤，不要求 selectedDeviceId

#### Scenario: 飞行成功但研判失败

- **GIVEN** 远端飞行投影已成功
- **WHEN** 业务 AI 超时
- **THEN** 业务 Run 显示失败或暂停，保留远端成功状态且不宣称全流程成功
