## Purpose

让用户从项目智能体的查询回答进入设备、任务和证据页面进行核验时，保持同一会话及其上下文；导航继续沿用业务页面原有权限边界，防止查看证据时意外中断正在进行的工作。

## ADDED Requirements

### Requirement: 核验项目证据时保留会话

系统 SHALL 对智能体 Markdown 回答中的根相对项目页面链接使用不刷新整页的导航；离开智能体页面后，原会话 SHALL 可在悬浮面板继续查看并返回完整会话。

#### Scenario: 从回答核查设备
- **GIVEN** 用户已在当前项目智能体获得包含设备链接的回答
- **WHEN** 用户点击回答中的 `/projects/1/devices/?selected=2` 页面链接
- **THEN** 设备页面打开，原会话保持为悬浮会话，返回完整会话后仍能看到原有回答。

### Requirement: 非项目页面链接保持原有行为

系统 SHALL 保留外站和协议相对链接的新窗口行为，API、下载与其他非项目页面地址 SHALL 不使用项目客户端导航。链接跳转 MUST 不批准待执行操作或更改设备状态。

#### Scenario: 打开外站与媒体接口
- **GIVEN** 回答包含外站或 API 媒体地址，并存在待授权操作
- **WHEN** 用户打开外站链接或 API 媒体链接
- **THEN** 沿用普通浏览器链接行为，待授权飞行状态不发生变化。

### Requirement: 静态部署支持项目页面导航

系统 SHALL 在生产静态部署中为合法项目页面地址提供对应的构建时导航数据，不以整页刷新替代正常客户端导航。未知页面、缺失文件及含有路径穿越的请求 MUST 返回 404。

#### Scenario: 读取项目页面导航数据
- **GIVEN** 应用已静态构建且设备页面导航数据存在
- **WHEN** 客户端请求项目设备页面的 index.txt 或分段导航数据
- **THEN** 返回对应导出文件，浏览器保留共享会话状态。

#### Scenario: 拒绝无效静态数据路径
- **GIVEN** 客户端请求未知页面、缺失数据或包含点段的路径
- **WHEN** 静态服务解析请求
- **THEN** 返回 404，不访问宿主文件系统或业务数据。
