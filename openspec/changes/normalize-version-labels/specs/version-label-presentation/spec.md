## Purpose

统一平台现有名称与版本组合的展示格式，使用户能够直接识别所引用的资源版本，同时保留业务元信息的真实含义，避免误把数据库主键、状态或版本指纹显示为数字版本。

## ADDED Requirements

### Requirement: 名称版本展示
系统 SHALL 将现有使用中点连接名称与明确版本的展示改为名称@v版本；已有 v 前缀不得重复添加。版本指纹 SHALL 使用名称@原指纹，保留原始值。

#### Scenario: 展示明确数字版本
- **GIVEN** 类型、驱动、素材或研判引用具有名称及版本 1
- **WHEN** 展示名称与版本组合
- **THEN** 使用名称@v1，不使用中点连接名称与版本。

#### Scenario: 版本值已经包含前缀
- **GIVEN** 版本值为 v1.0.0
- **WHEN** 展示名称与版本组合
- **THEN** 使用名称@v1.0.0，不显示重复的 vv。

#### Scenario: 指纹与非版本信息
- **GIVEN** 目录包含版本指纹、版本记录 ID、数量或状态
- **WHEN** 修改名称与版本格式
- **THEN** 指纹保留原值，记录 ID 不伪装成版本号，其他中点用途保留供用户决定。
