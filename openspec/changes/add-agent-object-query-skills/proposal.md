## Why

已录制自然语言授权飞行，需要补充影像查询、专业规则和本地视觉计算的演示。当前 Agent 可读算法运行，但缺少可复用技能加载、候选目标图像输入和可追溯的筛选结果。

## What Changes

- 增加内置巡检目标查询 Skill，Agent 按需加载，工具记录显示版本与规则。
- 增加只读 query_objects 工具：列出检测运行，查询类别/置信度，向模型提供经版本校验的原图和候选裁剪，核验选中目标 ID。
- 结果页面展示按目标 ID 筛选的框，允许恢复全部目标和导出待核查清单。
- 记录两段现有录像、后续补录提示词、DGX/StepFun 分工与验证边界。
- 本轮复用已有检测模型；不部署开放词汇模型、不新增实飞动作、不自动认定违规。

## Capabilities

### New Capabilities
- `agent-object-query`: 可追溯自然语言目标查询与行业技能加载。

### Modified Capabilities

无。

## Impact

影响 Go 聊天工具、内置 Skill、算法结果页和演示文档。复用既有 sqlc 查询、媒体读取及权限，不新增迁移或模型服务依赖。仅当前项目可查询，图像预览核对运行输入的版本和 checksum；图像不保存入会话。已有异步识别和写授权流程保持兼容。
