## Context

总览通过 OverviewMap 复用 ProjectMap，底图为 OpenFreeMap Liberty，MapLibre 5 已支持 globe 投影。其他地图页面复用同一组件，需要限制控件的启用范围。

## Goals / Non-Goals

通过投影与镜头状态组合实现用户可辨识的地球；不重建地图实例，不改变数据接口。功能范围见 proposal。

## Decisions

- 使用 MapLibre 原生 globe/mercator，避免引入第二个渲染器。通过 react-map-gl 的 projection 属性保持投影状态，地图引用负责镜头动画。
- ProjectMap 增加可选 showProjectionControl，仅总览启用。切换按钮放在现有图层控件上方，不遮挡全屏按钮。
- 进入地球时保存中心、缩放、bearing、pitch，保持中心、缩放、bearing，仅将 pitch 调整为 55 度；返回平面恢复保存的镜头。用户自行缩小可看到球体。
- 总览取消素材和识别区域的排除，让用户能比较所有已有地图要素。运行轨迹仍跟随设备类型筛选。
- 当前 Liberty 已包含 building-3d（openmaptiles/building），在 zoom >= 14 使用 render_height/render_min_height 拉伸建筑。直接复用，不引入新服务或模型依赖。OSM 数据覆盖和高度完整度决定实际效果。
- 本地预览使用独立 localhost 服务提供标明“模拟数据”的项目快照，包含每类要素，不连接业务数据库，不写入线上。示例文件保存在忽略的 .build 中。
- 切换时停止旧动画；减少动画偏好使用 jumpTo。加载前禁用按钮，保持已有图层和弹窗状态。
- 不增加存储或权限通道；所有地图实体继续来自授权项目快照。

## Risks / Trade-offs

- 高缩放下地球曲率不明显 → 用倾斜视角展示建筑体量，完整球体由用户主动缩小查看。
- 部分地区建筑高度缺失 → 明确建筑来自 OSM 底图，不能作为测量成果。
- 数据要素密集 → 保留已有类型和图层筛选，不新增聚合范围。

## Migration Plan

按当前静态前端构建发布；回退两个地图组件及对应规范即可，无数据库迁移。

## 三维装饰修订

- 按钮简称改为 3D。总览加载及样式加载时同步底图 building 挤出图层可见性，平面隐藏、3D 显示。
- 将巡检区域的每条环边转换为窄四边形，分 16 个高度带递减透明度，叠加竖向立柱。支持内环及多面；跳过无效及零长度边，限制几何数量。80 米为装饰高度，不读取或修改区域测量值。
- 告警标点增加不接收鼠标事件的 CSS 向上渐隐线，锚定原坐标，保留闪烁和减少动画行为。
- 删除本地示例左下角解释浮层；模拟数据仍由项目和实体名称标明。

## 标点样式再次修订

用户取消告警标点渐隐定位线，删除对应 DOM 和 CSS，保留闪烁光圈；该决定替代前文告警定位线设计。算法识别区域继续使用平面填色。

## 控件位置修订

视角切换独立放在地图右上角，左侧图层控件预留空间避免重叠；复用 SiteHeaderActions 将总览全屏入口放到 AeroSight 横栏右端。全屏主画面从横栏下方展开，保留顶部退出按钮，其他工作区沿用原入口。
