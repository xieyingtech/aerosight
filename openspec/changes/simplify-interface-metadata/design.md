## Context

当前中点位于 JSX 文本、动态模板、属性、服务端名称和历史记录。外部航线、模型和飞行任务使用带 AeroSight 摘要的持久化名称进行重试对账。

## Goals / Non-Goals

**Goals:** 区分状态、数量、名称与字段信息，保留全部数据与操作入口。

**Non-Goals:** 历史重写、对账名称改名、数据迁移、权限与执行语义变更。

## Decisions

- 静态与动态元信息按语义分组为可换行的独立项；结构字段分行。数量标题使用括号；状态与名称独立展示；列表项使用真正列表结构。
- 简短提示改完整句子；Enter 提示保持原文。
- 字符串属性、下拉选项和原生 tooltip 无法显示标签，采用有语义的括号或换行，不统一替换为另一个分隔符。
- 保留对账函数产生的外部名称及验证历史兼容的契约；只修改以主键或外部 ID 定位的展示名称。不迁移已有记录。

## Risks / Trade-offs

- [名称参与远端对账] → 保留原生成格式及对应历史断言。
- [布局换行或嵌套影响点击] → 类型检查、生产构建及重点页面验收；保留链接和控件。

## Migration Plan

部署文字与布局变更；无需数据库迁移。回滚代码即可恢复展示，生产历史名称不重写。
