## Purpose

定义统一 HTTP 服务向浏览器、设备集成和运维暴露的公共行为，包括请求关联、错误响应、安全约束、资源使用和可观测性，保证多个职责合并后仍能稳定提供普通请求与长连接服务。

## ADDED Requirements

### Requirement: 请求关联与错误边界

系统 SHALL 为请求提供可关联的请求 ID、结构化日志和既有 API 兼容的错误响应；日志 MUST 不包含密码、会话 Cookie、访问密钥或完整敏感正文。

#### Scenario: 请求异常

- **GIVEN** 普通 API 在处理时发生未预期异常
- **WHEN** 响应尚未写出
- **THEN** 返回 500 与请求 ID，记录错误但不暴露堆栈和密钥

#### Scenario: 流式异常

- **GIVEN** 流式响应已发送部分内容
- **WHEN** 后续处理发生异常
- **THEN** 终止流并记录请求 ID，不追加普通 JSON 错误破坏协议

### Requirement: 限流与可信来源

系统 SHALL 使用可信来源或已认证用户作为限流键，超限返回 429 与 Retry-After；不可信转发头 MUST 不能绕过限流，紧急停止不得被普通写请求额度耗尽阻断。

#### Scenario: 伪造来源

- **GIVEN** 客户端来自非可信代理地址
- **WHEN** 轮换 X-Forwarded-For 反复尝试登录
- **THEN** 请求仍受同一真实连接来源额度限制

#### Scenario: 急停独立

- **GIVEN** 用户有急停权限且普通写请求额度已耗尽
- **WHEN** 提交有效紧急停止请求
- **THEN** 请求仍进入授权与安全处理，不因普通写额度返回 429

#### Scenario: 写请求超限

- **GIVEN** 用户已超过配置的普通写额度
- **WHEN** 继续调用普通写 API
- **THEN** 返回 429 与 Retry-After，业务没有新增副作用

### Requirement: 流式与普通请求资源策略

系统 SHALL 对普通 API 和上游操作设置可取消的期限，对 SSE 和文件流保持必要的实时写入与取消语义；长连接不得被普通 API 的固定期限或压缩缓冲截断。

#### Scenario: 普通查询超时

- **GIVEN** 普通请求超过其配置期限
- **WHEN** 数据库操作仍未完成
- **THEN** 取消操作并返回适当错误，不继续提交已取消业务事务

#### Scenario: SSE 持续运行

- **GIVEN** 用户权限和会话有效
- **WHEN** SSE 持续超过普通 API 超时时长
- **THEN** 连接继续发送心跳和事件，断开后释放资源

#### Scenario: 资产分段访问

- **GIVEN** 用户持有有效资产访问权限
- **WHEN** 请求合法 Range
- **THEN** 返回正确范围和响应头，不被文本压缩改变字节范围

### Requirement: 安全响应与监控

系统 SHALL 提供兼容前端所需资源的安全响应头、受控指标端点及低敏日志；指标不得以用户或项目 ID 形成无限增长标签。

#### Scenario: 正常页面资源

- **GIVEN** 生产安全策略已启用且地图和媒体地址已允许
- **WHEN** 打开地图与实时页面
- **THEN** 必要脚本、worker 和媒体正常加载，禁止未授权脚本来源

#### Scenario: 指标访问

- **GIVEN** 请求者未提供管理员会话或有效抓取凭据
- **WHEN** 请求 /metrics
- **THEN** 请求被拒绝且不泄露内部指标

#### Scenario: 带凭据请求

- **GIVEN** 请求包含 API 密钥或会话头
- **WHEN** 请求被记录
- **THEN** 日志只包含必要元数据，不包含敏感凭据
