## Purpose

定义原前端服务端业务职责迁入统一应用后的接口兼容与功能完整性，覆盖页面数据读取、业务写入、实时事件、资产及外部回调和 AI 工具行为，防止部署方式改变导致功能或授权退化。

## ADDED Requirements

### Requirement: 现有功能与接口兼容

系统 SHALL 在统一服务提供全部现有业务 API、页面数据与表单操作；除明确声明的登录和页面 URL 变更外，已有业务接口的方法、路径、字段、错误码和权限语义 MUST 保持。

#### Scenario: 原业务接口调用

- **GIVEN** 客户端使用迁移前业务 API 契约
- **WHEN** 请求设备、任务、算法、报告或连接器接口
- **THEN** 收到兼容的数据形状、状态码及错误语义

#### Scenario: 原服务端页面与表单

- **GIVEN** 页面原先读取数据库或提交 Server Action
- **WHEN** 用户加载页面或创建团队/项目
- **THEN** 通过显式 API 完成等价操作，并有加载、空数据和失败状态

#### Scenario: 认证重定向隔离

- **GIVEN** 用户会话无效
- **WHEN** 请求 JSON 业务 API
- **THEN** 返回认证错误，不返回登录页 HTML 作为成功响应

### Requirement: 写入原子性与业务安全

系统 SHALL 保留业务写入、审计、幂等、outbox、项目事件和设备安全规则，不得因服务合并产生部分成功或重复控制。

#### Scenario: 事务中途失败

- **GIVEN** 操作需要同时写业务状态、审计和 outbox
- **WHEN** 其中任一步失败
- **THEN** 全部回滚，不留下无审计状态或孤立事件

#### Scenario: 重复控制请求

- **GIVEN** 相同幂等键的命令已接受
- **WHEN** 客户端因重试再次提交
- **THEN** 按已有规则返回原结果或冲突，不重复发出控制命令

### Requirement: 项目实时事件连续性

系统 SHALL 保留 SSE 编码、游标续传与 snapshot-required 协议，Last-Event-ID 优先于查询 cursor；保留回放上限 500、15 秒心跳和权限/会话复查，不长期占用每连接独立数据库连接。

#### Scenario: 断线续传

- **GIVEN** 客户端带有效 Last-Event-ID 重连
- **WHEN** 服务器存在该游标后的事件
- **THEN** 按顺序发送后续事件，不从任意新快照偷偷跳过

#### Scenario: 过期游标

- **GIVEN** 请求游标已超出可回放窗口
- **WHEN** 连接 SSE
- **THEN** 按原协议发送 snapshot-required，客户端可重新读取快照

#### Scenario: 权限撤销断流

- **GIVEN** SSE 正在推送项目数据
- **WHEN** 成员资格被撤销
- **THEN** 在 15 秒复查周期内停止推送并释放资源

### Requirement: 外部集成与资产访问兼容

系统 SHALL 在统一应用端口提供现有算法回调、签名资产和媒体鉴权，保留签名、有效期、租户、请求体限制及重放处理语义。

#### Scenario: 有效回调

- **GIVEN** 算法运行存在且回调签名有效
- **WHEN** 算法服务向更新后的统一地址回调
- **THEN** 结果按原流程落库并触发后续任务

#### Scenario: 非法签名资产

- **GIVEN** 资产 URL 签名过期或资源作用域不符
- **WHEN** 请求资产内容
- **THEN** 拒绝访问，不因静态托管回退泄露文件

#### Scenario: 媒体鉴权

- **GIVEN** MediaMTX 调用平台鉴权入口
- **WHEN** 提供有效或无效的既有访问凭据
- **THEN** 分别按原协议允许或拒绝，媒体传输服务继续独立运行

### Requirement: AI 行为等价

系统 SHALL 保留当前 provider 和模型配置、最近 20 条对话历史、最多 8 步工具执行、六个只读工具、证据引用和消息落库；每次工具操作 MUST 按当前项目范围授权。

#### Scenario: 查询型对话

- **GIVEN** 用户有 agent:use 权限且 provider 可用
- **WHEN** 提交需要查询设备或任务的消息
- **THEN** 查询当前项目并返回中文回复与证据，消息保存到原会话

#### Scenario: 越界工具参数

- **GIVEN** 模型返回其他项目资源或非法工具参数
- **WHEN** 执行该工具调用
- **THEN** 调用被拒绝，不读取越界数据或执行设备控制

#### Scenario: 上游故障

- **GIVEN** AI 上游超时或返回错误
- **WHEN** 执行对话或 provider 测试
- **THEN** 返回可识别错误，不泄露密钥，不伪造成功回复
