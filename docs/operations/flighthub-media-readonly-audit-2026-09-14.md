# 司空历史飞行与图片视频只读实测（2026-09-14）

## 结论

当前 Token 能查询历史飞行；OpenAPI 尚未取得图片或视频，但后续网页实测已确认真实照片与视频存在且能预览（见末尾复核）。此前依据无时间条件的空列表作出的“当前项目无可读历史飞行”结论过早，本记录明确纠正。

## 查询范围与实际结果

- Token 可读项目：1 个，名称“深圳协盈智慧安防科技保安服务有限公司”，与配置的连接器项目一致。
- 可读设备：1 组机场/无人机，分别查询而非假设二者返回相同历史。
- `/openapi/v2.0/flight-task/list`：无时间范围为空；以秒级 Unix 时间指定近 30 天返回 25 条，近一年 40 条；从项目创建时间 2024-11-13 至本次查询返回 77 条。最初额外探测使用毫秒单位的范围返回空，随后按仓库契约中的秒级单位纠正；仅秒级结果计入结论。
- 机场历史含 manual 飞行，部分没有 wayline_uuid。现有客户端只接受 immediate/timed/recurring/continuous 且要求非空航线，因而拒绝整批历史。本次诊断读取官方成功响应中的已返回 UUID，直接查询对应媒体，不修改生产数据或伪造成功状态。
- 最近任务接口：机场返回数字 status/task_type 的另一种结构，当前同用字符串类型解析器报 schema incompatible；无人机返回空列表。不能把解析失败当零记录。
- 当前直播录制任务列表返回空；该接口不证明不存在历史录制文件。

## 77 个历史架次的媒体请求

逐一调用 `GET /openapi/v2.0/flight-task/{task_uuid}/media`，包括成功、终止、部分完成和启动失败记录，未仅限成功飞行。

| code=0，list=null | 19 | 接口返回空列表；客户端当前误报 schema incompatible |
| code=217028，dir not exist | 21 | 对应媒体目录不可用 |
| code=219021，服务器异常，请稍后重试 | 32 | 远端服务失败，不能据此断言没有素材 |
| code=0，非空列表 | 5 | 共 22 条返回项（有跨列表重复），21 条 unsupported 目录项、1 条 ppk/DAT，没有 image/video |

目录项 URL 的路径为 `/`，不能当作可下载照片。非空列表使用官方响应提供的 `file-storage.djicdn.com`，诊断客户端初始下载域名列表未包含该 CDN，曾返回 TEMPORARY_LINK_HOST_FORBIDDEN；该本地检查失败与远端无数据分开记录。

对唯一非目录的 DAT 链接独立进行 HTTPS GET Range `bytes=0-1023`，不附带司空 Token、不跟随重定向：HTTP 206，Content-Type application/octet-stream，Content-Range bytes 0-1023/609051，收到 1024 字节。这证明本次签名下载通道可用，但该文件是飞行日志，不是图片或视频。

## 边界与下一步

本次仅查询已配置凭据可读项目，远端 API 请求全部 GET，无起飞、计划创建、直播启动、录制启动等控制请求；业务数据库只读。原始响应/临时链接位于忽略目录 `.build`，未写入本文或提交文件。

本次没有获得图片/视频条目，所以尚未验证实际图片解码或视频播放。也不能据 32 个服务失败断言司空不存在素材。下一步应对照司空网页媒体库中已知存在的一张图片或一个视频，核对所属项目、架次和上传位置；对服务错误的具体 flight UUID 可向司空核查。此步骤不需要新飞行。

需要修复的连接器软件问题另行跟踪：历史扫描明确时间范围、接受真实只读 manual 历史、区分最近任务数字枚举契约、空媒体列表与远端业务错误的准确分类。不得为了读取历史放宽飞行创建接口的 immediate-only 约束。

### 官方合同核对

2026-09-14 重新读取[官方媒体接口文档](https://s.apifox.cn/4de4a239-c2cc-4572-9b65-90738289f37a/api-457309246)。公开文档说明支持 image/video/ppk、最多前 10000 项；参数为 task_uuid 路径和认证/项目/请求 ID/语言请求头，未列 folder_id、pid、recursive 等 query 参数。其公开成功示例本身包含 unsupported 的目录条目及根路径下载链接。当前官方目录中未发现通用媒体文件夹列表接口。

因此“只要递归读取就能修好”尚不成立：需要 DJI 明确支持的子目录查询方式或修复任务媒体接口。不得将网页内部接口视为已经支持 OpenAPI Token 的公开契约，也不得把目录 UUID 当 flight UUID 或猜测递归参数。

### 本地问题与远端问题分开处理

1. 本地 `client.request` 先校验 data 是否存在，后判业务码；远端 219021 没有 data，误归类 schema_incompatible。应先判 JSON/业务码，再仅对成功响应检查 data，并把已确认的 219021 分类为可有界重试的远端服务故障。该修复改善错误处理，不能让远端返回文件。
2. 默认临时链接主机未含 file-storage.djicdn.com。应对已核实的生产 CDN 显式配置允许，保留 HTTPS/用途/过期/重定向检查，下载不得携带 OpenAPI Token；目录根路径绝不可作媒体下载。放行主机只能解决链接验证，不能解决缺失的照片列表。
3. 历史列表需要秒级时间范围；manual/无航线的只读记录与 recent 数字枚举需要分别适配。不能扩展真实飞行创建权限。
4. 成功空列表、目录存在但只有目录项、远端错误须分别表达；不得把只列出父目录当成媒体完整采集，不得据此生成 no_issue。

### 快速闭环方案

短期可从司空网页下载已有真实素材，经现有资产导入流程进入检测和智能体研判；资产来源应记为导入文件，并保留任务/时间等来源元数据，不能标记 OpenAPI 自动同步已验收。算法供应商仍需配置并独立验收。

长期以公开 OpenAPI 完成自动媒体同步。应向 DJI 提交以下两个可复现案例（仅准备，未发送）：

- 同项目的任务 e1820319-cbf7-427c-b4dc-6b926c36946f，网页 folder_id=321446105 有两个 MP4；GET /openapi/v2.0/flight-task/{task_uuid}/media 返回 code=219021、服务器异常。详情接口成功，项目和目录映射已核实。请核查服务端媒体生成/列举错误。
- 任务 081de29a-24a6-46a3-bb63-8aa4a3c2a903，网页父目录 321460526 / Remote-Control 子目录 321463914 有 37 个影像；同一接口仅返回目录和 DAT。请提供受支持的递归/目录查询接口，或修复媒体接口展开子目录行为。

给厂商的正式材料应附最新 X-Request-Id、调用时间与脱敏响应；不包含 Token、签名链接或真实素材。修复验收应以这两个目录为样本：获取 MP4/JPEG 条目并实际读取文件字节，验证图片解码/视频可播放及来源关联。此轮仅定位、实测和更新记录，未修改生产连接器代码，未触发真实飞行。
