# 红花山烟火与夜间线索复核

## 适用请求
“找公园视频里疑似烟雾或明火”“夜间巡查有哪些需要复核的线索”。重点是证据检索和人工复核。

## 工作步骤
1. query_assets 核对素材来源、覆盖区域、可见光/热成像类型及采集时间。未提供热成像或温度标定，不可宣称测温或热异常识别。
2. search_media 用“烟雾”“明火”“夜间异常”等适合当前素材的语义查询检索片段。只有可信绝对采集时间时才提供成对 start/end；否则只检索已有素材并报相对时间。检索描述不是视觉确认结果。
3. 若需查看真实影像，按 query_inspection 的 photo/observation 或内置 inspection-object-query 的真实支持方式取得证据。普通对象检测模型未支持烟火类别时，明确不能据此排除火情。
4. 核对线索是否有多帧连续性、可能的反光/灯光/水汽等解释。没有图像输入就保持“待复核”，不编造已看见的内容，也不将单次无结果视为无火灾。
5. 输出：检索范围、候选片段与引用、已核实事实、未核实解释、建议人工核查。确有明显风险证据时建议值班人员按既有预案处置；不声称通知已经发送。

## 边界
不做人员生命状态或伤情诊断，不虚构夜间搜索能力。真实飞行、广播、通知或写入仍需现有工具及授权；此流程默认只读。DGX 本地并发复核和实时预警须有实际接入及测量后再展示。
