# 算法场景硬编码检查（2026-09-28）

平台页面和通用接口不得预设违建或其他具体算法类别。

本次全局检查发现并修正：

| 位置 | 原问题 | 通用行为 |
| --- | --- | --- |
| 项目地图、实时作业筛选 | 固定显示“疑似违建”图层 | “算法识别结果”图层，结果标签来自数据 |
| 项目快照与图层可用性 | 字段名 suspectedConstruction | algorithmResults |
| 时间线、态势详情、回放 | 使用特定业务字段和默认标签 | 使用通用算法结果，保留实际类别 |
| 聚合结果查询 | 将所有 group.label 覆盖为“疑似违建” | 返回实际 label |
| 历史事件列表、详情 | SQL、服务端和前端均覆盖事件标题 | 保留实际 event.title |
| 证据图片 | 固定描述为违建原图 | 算法识别结果原图 |
| 映射版本 | 缺少版本时虚构 suspected-construction/v1 | 返回空值，页面显示未提供 |
| 新事件数据库默认标题 | 默认疑似违建 | 默认算法识别结果 |

已删除违建专用模板及其引用，映射工具改为通用算法结果映射。测试和压测独立提供通用类别与配置，不保留专用模板或旧字段兼容分支。本地数据库检查未发现违建算法、检测、事件、规则、任务或案件数据。

同时检索火灾、烟火、垃圾、人数统计、人车船、道路病害等场景词，未发现通用页面或智能体服务中同类的固定场景呈现。厂商接口本身的能力名称仍使用对应连接器的真实定义。
